# Resume Website Task

## Goal

Transform my existing resume/portfolio website into a premium, modern,
professional developer portfolio.

The design should combine:

- Apple's premium, minimal, polished visual quality
- A subtle Spider-Man-inspired visual identity
- Strong typography and visual hierarchy
- Smooth, intentional animations
- Excellent responsive behavior

Do NOT copy Apple's website or Spider-Man artwork directly.
Use them only as design inspiration.

## Phase 1 — Understand the Existing Project

- Review the complete project structure before making changes.
- Identify the framework, dependencies, entry points, components, assets,
  styling system, and existing functionality.
- Understand the current design before replacing anything.
- Preserve useful existing components and functionality.

## Phase 2 — UI/UX Improvements

Improve:

- Overall layout
- Typography
- Spacing
- Visual hierarchy
- Navigation
- Hero section
- About section
- Skills section
- Projects section
- Experience/education sections if present
- Contact section
- Footer

Do not remove existing sections or functionality unless there is a strong
reason to do so.

## Visual Direction

The website should feel:

- Premium
- Minimal
- Futuristic
- Professional
- Confident
- Developer-focused

### Apple-inspired qualities

Use:

- Clean layouts
- Generous spacing
- Strong typography
- Refined visual hierarchy
- Subtle depth
- Smooth transitions
- Minimal visual clutter

### Spider-Man-inspired qualities

Use subtle inspiration through:

- Web-like visual patterns
- Red/black/dark visual accents
- Subtle geometric elements
- Motion inspired by web movement
- Heroic/confident visual presentation

Do NOT use copyrighted Spider-Man characters, logos, movie screenshots,
or copied artwork.

## Animation

Animations should be:

- Smooth
- Fast and responsive
- Subtle
- Purposeful
- Performance-friendly

Use animation for things such as:

- Page/section entrances
- Hover states
- Navigation interactions
- Project cards
- Buttons
- Scroll-based reveals

Avoid excessive animations that make the website distracting or slow.

Respect `prefers-reduced-motion` where appropriate.

## Responsive Design

The website must work properly on:

- Mobile
- Tablet
- Laptop
- Desktop
- Large desktop screens

Check:

- Navigation
- Typography
- Images
- Cards
- Spacing
- Buttons
- Sections
- Animations

No horizontal scrolling should occur because of layout issues.

## Functionality

- Preserve all existing functionality.
- Do not break existing links.
- Do not break navigation.
- Do not remove working features unnecessarily.
- Do not invent personal information.
- Do not invent skills, experience, projects, education, or achievements.
- Use existing content unless restructuring is necessary.

## Code Quality

- Keep the code clean and maintainable.
- Reuse components where appropriate.
- Avoid unnecessary dependencies.
- Follow the project's existing architecture where practical.
- Do not rewrite the entire application unnecessarily.
- Prefer small, controlled improvements over destructive rewrites.

## Validation

After making changes:

1. Run the existing tests.
2. Run the production build.
3. Fix build errors.
4. Fix runtime errors caused by the changes.
5. Check for obvious console errors.
6. Check responsive layouts.
7. Review animations for performance.
8. Verify existing functionality still works.

## Completion Criteria

The task is complete only when:

- The project builds successfully.
- Existing functionality still works.
- No important features were removed.
- The website is responsive on mobile, tablet, and desktop.
- The UI feels premium and polished.
- The Apple-inspired minimal quality is achieved.
- The Spider-Man-inspired visual identity is subtle and professional.
- Animations are smooth and purposeful.
- There are no obvious console errors.
- There are no obvious responsive layout issues.
- Existing tests pass, if tests exist.
